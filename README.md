# OpenPlanr skills have moved to openplanr/OpenPlanr

This repository is archived and no longer maintained. The OpenPlanr skills for Claude Code,
Codex and Cursor are built in the [OpenPlanr repository](https://github.com/openplanr/OpenPlanr)
and ship with the [`openplanr`](https://www.npmjs.com/package/openplanr) npm package.

```bash
npm install -g openplanr
openplanr setup
```

`openplanr setup` detects the coding agents on the machine, shows what it will write, and
installs the skills. The [documentation](https://openplanr.dev/docs) covers each coding agent.

The `SKILL.md` files here are kept only as pointers, so registries that indexed this repository
send people to the current version.
